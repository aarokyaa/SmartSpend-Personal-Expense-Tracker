# SmartSpend — Project Statement

## Problem Statement
Students and young adults often record expenses inconsistently and lack an organized view of spending, budgets and future expenses.

## Proposed Solution
SmartSpend is a Java command-line expense tracker that stores income/expense data in CSV and provides CRUD, budgeting, analytics, anomaly detection, linear-regression prediction and report generation.

## Scope
Income/expense recording, CRUD, budgets, category/monthly analytics, unusual-spending detection, prediction, CSV persistence and reports.

## Target Users
College students, young adults and individuals wanting a lightweight personal expense tracker.

## High-Level Features
Transaction CRUD, budgets, analytics, anomaly detection, prediction and report export.
